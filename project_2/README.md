# Project 2: Static Website on Amazon S3 with Terraform

Creates an S3 bucket with static website hosting, a public-read bucket policy,
and uploads index.html and error.html.

## Usage
    terraform init
    terraform fmt && terraform validate
    terraform plan
    terraform apply
    terraform destroy
