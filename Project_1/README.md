# Project 1: Linux EC2 Web Server with Terraform

Creates a VPC, public subnet, internet gateway, route table, security group
and an Amazon Linux 2023 EC2 instance that installs Apache via user_data.

## Usage
    terraform init
    terraform fmt && terraform validate
    terraform plan
    terraform apply
    terraform destroy
